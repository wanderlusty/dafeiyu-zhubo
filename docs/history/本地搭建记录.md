# 小白主播本地搭建记录

更新：2026-11-03。项目位于 `D:\PRJ\ds-zhubo`；实际测试结果见 [功能验收清单](功能验收清单.md)。

## 启动与控制

双击 [`启动小白.cmd`](启动小白.cmd) 打开 `http://127.0.0.1:3090/`。它会启动项目内 DSH 和独立控制台；服务已经运行时只会打开控制台。关闭 PowerShell 窗口会停止由它启动的 DSH，网站与 QQ/OBS 连接也会失去后台。

控制台分为 QQ 聊天、B 站刷视频和 B 站直播。先在直播页做本地彩排、模拟弹幕、检查 OBS 画面；确认账号、标题和分区后，才点击“确认正式开播”。这个按钮会向 B 站申请开播并启动 OBS 推流，对外可见。

## 固定工作区

小白的工作区是 `.dsh-home/worlds/ds/room`，设定入口为 [`AGENTS.md`](../../.dsh-home/worlds/ds/room/AGENTS.md)。QQ 沿用家会话，浏览与直播的新会话进入该目录。B 站值班改成简短开场语加固定文档，不再把整篇章程重复贴进每轮会话。安装脚本会从 [`workspaces/platform/config/workspace-AGENTS.md`](../../workspaces/platform/config/workspace-AGENTS.md) 恢复缺失的工作区设定，保留用户已编辑的版本。

旧的未分组会话属于历史记录，没有删除。B 站日报与角色世界的长期记忆仍由 `Sync-Bili-Memory.ps1` 桥接；直播独立会话仅可访问已筛选的 B 站浏览记忆，不能读取 QQ 私聊文件。

## 安装与组件

如需重建依赖，先停止本地服务，再运行 `powershell -ExecutionPolicy Bypass -File .\Setup-Local.ps1`。脚本安装项目固定的 `dsh-bili-scroll`、`dsh-world`、`dsh-livestream` 本地包和所需 Python 环境，并设置受限的 `bili-duty` profile。OpenCode Go 的 API Key 位于 DSH 本机凭据库，不在本项目文档中。

普通 QQ 小号通过 SnowLuma/OneBot 连接；本机登录态由账号持有人维护。QQ 只允许白名单中的私聊，群聊关闭。OBS 在 `D:\obs-studio`，已配置浏览器源与 obs-websocket。直播账号沿用 B 站刷视频的本机登录态。
